# 🔺 Triangle Explorer

**Triangle Explorer** is an interactive mathematics learning tool that helps users explore and understand triangle classification through experimentation.

Instead of simply memorizing the names of triangles, users can drag the vertices of a triangle and see how its side lengths and angles change in real time.

The tool can be used by anyone who wants to learn, revise, or test their understanding of triangles.

## ✨ What Can You Explore?

Triangle Explorer classifies triangles in two ways:

### By Side Lengths

- **Equilateral**
- **Isosceles**
- **Scalene**

### By Angles

- **Acute**
- **Right**
- **Obtuse**

Every triangle has both a side-based classification and an angle-based classification. By experimenting with the shape, users can see how these classifications relate to each other.

## 🌍 Learn Through Real-World Examples

The tool connects triangle types with examples from the real world.

Users can explore how different types of triangles appear in things such as:

- 🏕️ Tents
- 🏠 Roof structures
- 🌉 Bridges
- 🏗️ Structural designs
- 📐 Everyday geometric shapes

The goal is to connect an abstract mathematical classification with something users can actually recognize in the world around them.

## 🎯 Challenge Yourself

Triangle Explorer includes interactive challenges where users are asked to create a specific type of triangle.

For example:

> **Can you make a Right Triangle?**

Users can experiment by moving the vertices until they achieve the requested classification.

## 🧠 Test Your Understanding

A built-in quiz allows users to test what they have learned and receive immediate feedback.

This makes the tool useful not only for exploration but also for self-assessment and revision.

## 👩‍🏫 Who Is It For?

Triangle Explorer is **not limited to a particular grade level**.

It can be used by:

- School students learning geometry
- Teachers introducing triangle classification
- Students revising mathematical concepts
- Anyone who wants to explore geometry interactively

The interface is intentionally simple so that learners can discover the concepts through interaction rather than relying only on memorization.

## 🚧 Current Limitations

The current version has some minor **measurement and geometric precision limitations** when users drag the triangle vertices.

These do not prevent the main learning experience, but the measurement and classification behaviour could be further refined in future versions.

### Future Improvements

Possible future improvements include:

- More precise side-length measurements
- Improved angle measurement and display
- More robust handling of edge cases
- Additional challenges
- More real-world examples
- Expanded quiz content
- Accessibility improvements
- Additional geometry concepts

## 💡 Why I Built It

Triangle Explorer was created as a small example of how interactive technology can make mathematical concepts easier to explore.

Rather than presenting triangle classification as something to memorize, the tool encourages learners to **experiment, observe, make mistakes, and discover the relationships themselves**.

## 🤖 Created During AI Training

This project was developed as part of a **3-day AI training experience**.

AI tools were used to support the development process, while the project itself was designed around a specific educational idea: using an interactive environment to make geometry more engaging and exploratory.
